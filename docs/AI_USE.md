# Declaration of AI usage

As allowed by section 13 of the proposal, the team used an AI coding assistant (Anthropic Claude, through Claude Code) for:

- code scaffolding, refactoring the code into the `driftlens/` package, and the data-download script;
- writing and extending unit tests;

AI tools were **not** used to fabricate data, results or citations. Every number in the report comes
from the saved files in `results/`, produced by `scripts/runExperiment.py` on the public UCI file
(SHA-256 is recorded in `data/raw/SOURCE.json` and in each `metadata.json`).
